## Getting Started

Follow these steps to set up and run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ColWrigh/SubScan.git
cd your-repo-name
```

---

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

---

### 3. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

---

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

This will install all required libraries for the project.

---

### 5. Run the Application

```bash
python [main_script].py
```
---

## Dependencies

All dependencies are listed in `requirements.txt`.

To update dependencies:

```bash
pip freeze > requirements.txt
```

---

## 📌 Notes

* Always activate the virtual environment before running the project.
* Dependencies are isolated to avoid conflicts with your system Python.
* The compiled version includes all dependencies, so users do not need to install anything.
